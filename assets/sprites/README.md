# 스프라이트 교체 가이드

이 폴더에 아래 이름으로 PNG 파일을 넣고 새로고침하면 게임에 바로 적용됩니다.
파일이 없는 항목은 코드로 그린 기본 그래픽이 대신 표시되므로, **하나씩 그려서 넣어도 게임은 항상 정상 동작합니다.**

## 제작 팁

- **배경은 투명**(알파 채널)으로 저장하세요.
- 원본 해상도는 자유입니다. 표시 크기의 정수배(예: 캐릭터 24x32를 2배로 표시)로 그리면 도트가 깔끔하게 보입니다.
- 게임이 `imageSmoothingEnabled = false`로 그리기 때문에 픽셀아트가 뭉개지지 않고 또렷하게 확대됩니다.
- 캐릭터의 "발끝" 기준이란: 이미지의 아래쪽 가운데가 캐릭터가 서 있는 바닥 지점에 닿는다는 뜻입니다. 캐릭터 아래에 여백을 남기지 마세요.
- 메뉴나 손님을 새로 추가하면 (`js/data.js`) 파일명 규칙(`food_새id.png`, `cust_새id.png`)에 맞춰 스프라이트도 추가하면 됩니다.
